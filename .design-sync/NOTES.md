# design-sync notes — @pairlens/ui

Repo-specific gotchas for future syncs of the Pairlens design system to claude.ai/design.

## Build model (how this repo is wired)

- Shape: **package** (no Storybook). Discovery is driven by a generated **catalog** (one primary
  export per component file) set as `package.json` `"types"` → `dist/catalog.d.ts`. Without a `types`
  field the ts-morph pass finds `index.d.ts` at pkg root (absent) and discovers **0** components — the
  catalog + types field is load-bearing.
- The bundle `--entry` is a **full `export *` barrel** (`packages/ui/.ds-tmp/bundle-entry.ts`) so all
  ~310 sub-parts (CardHeader, DialogContent, SelectItem…) are importable in previews and available to
  the design agent, while the catalog keeps discovery to exactly **65 primary component cards**.
- `.design-sync/prebuild.mjs` (wired as `cfg.buildCmd`) does all of it deterministically: tsc `.d.ts`,
  regenerate catalog + bundle-entry + category docs, compile Tailwind, strip `@font-face`. Re-run it
  (or `cfg.buildCmd`) before the converter on every sync.
- **CSS**: Tailwind v4 source (`src/styles.css`) is compiled by the prebuild via `@tailwindcss/cli` to
  `packages/ui/.ds-tmp/compiled.css` (`cfg.cssEntry`). `@font-face` blocks are stripped from it — the 3
  `@fontsource-variable` families (Mozilla Text / Playfair Display / JetBrains Mono) ship via
  `cfg.extraFonts` pointing at each package's `index.css` (converter copies woff2 + rewrites urls).
- Grouping: `.design-sync/docs/<Name>.md` category stubs (regenerated by prebuild) set the 9 groups.
  All components live in `src/components/ui/`, so src-derived group is always `general`; the doc
  category is what produces Buttons/Forms/Overlays/etc.

## Authoring gotchas (apply to any animated / overlay component)

- **Frozen capture clock freezes JS-driven animations at frame 0.** `package-capture.mjs` pins
  `performance.now()`, so any component whose resting look depends on an entrance animation captures
  stuck at its initial frame. Fixes (author-side, in the preview `.tsx`):
  - recharts (ChartContainer): pass `isAnimationActive={false}` on every series.
  - framer-motion / motion opacity fades (ShimmeringText): inject a `<style>` forcing
    `opacity: 1 !important` on the animated element (beats motion's inline `opacity:0`).
  - Any slide/zoom entrance (Sheet, Drawer, Dialog content, Carousel): prefer a static open state;
    if it renders mid-transition, force the resting transform/opacity via `!important` in the preview.
- **Overlays render OPEN**: pass `defaultOpen` (and `defaultValue` for Select) so the open state
  renders statically; give the wrapper `minHeight: 320`. Verified: Dialog, Select, Combobox.
- **base-ui composition uses a `render` prop**: e.g. `<DialogClose render={<Button>Cancel</Button>} />`.
- **base-ui Select (closed) shows the raw value**, not the item label, when the content popup is
  unmounted (items aren't registered) — cosmetic; the open state shows labels correctly.
- **`type="number"` inputs reject comma-formatted defaultValue** — use `inputMode="decimal"` to show
  formatted prices like `3,410.00`.
- **No remote images** (network blocked in capture) — Avatar etc. must use text/fallback, not `src`.
- **base-ui `Menu.GroupLabel` MUST be inside a `Menu.Group`.** A bare `DropdownMenuLabel`/
  `ContextMenuLabel` under `*MenuContent` throws in a _post-mount effect_ → unmounts the whole React
  root → cell captures **completely blank** while capture still reports "0 errors" (the mount
  try/catch only catches synchronous throws). Always wrap labels+items in `*MenuGroup`.
- **Open standalone `Menu.Root` is modal by default** → inert-hides the page → blank static capture.
  Pass `modal={false}` on the open `DropdownMenu`/`MenubarMenu` root. (ContextMenu is always modal but
  captures fine.)
- **Accordion/Collapsible expand animation** is height-driven (`--accordion-panel-height`,
  `data-starting-style:h-0`) → frozen at height 0. Even with `defaultValue`/`defaultOpen`, force
  `[data-slot='accordion-content']{height:auto !important}` (and `[data-slot='collapsible-content']`).
- **NavigationMenu** open content: `defaultValue` + item `value` + force
  `[data-slot='navigation-menu-content']{opacity:1;transform:none !important}`.
- **embla Carousel**: force `[data-slot='carousel-content'] > div{transform:none !important}` and add a
  `margin: 0 52px` gutter so the `-left-12/-right-12` prev/next arrows aren't clipped.
- **Sidebar**: use `collapsible="none"` (else the `hidden md:block`+fixed path renders blank in the
  narrow capture); wrap in `<SidebarProvider style={{height}}>` (inline beats its `min-h-svh`).
- **Standalone icon components** (BellIcon…) render fine at an explicit ~56px size + color. But their
  motion-driven path draw (`pathLength`) can capture at 0 when used incidentally — for decorative
  icons _inside_ a composition, plain inline `<svg>` is more reliable than the DS motion icon.
- **`Toaster` (sonner)** needs `toast` from the SAME sonner instance as the bundled `<Toaster>`. The
  prebuild re-exports `export { toast } from 'sonner'` on the bundle entry so
  `import { Toaster, toast } from '@pairlens/ui'` share one ToastState store; a preview importing
  `toast` from `'sonner'` directly hits a second store and renders blank. Keep the bundle re-export.

## Known DS source quirks (found while authoring — candidates to fix upstream, not blockers)

- `src/components/ui/aspect-ratio.tsx`: sets `style={{'--ratio': ratio}}` then spreads `{...props}`
  AFTER, so a caller-passed `style` clobbers the `--ratio` var and the box collapses to 0 height.
  Preview workaround: set `aspectRatio` + width inline instead of relying on the component's `ratio`.

## Re-sync risks (what can silently go stale)

- `packages/ui/.ds-tmp/` and `dist/` are gitignored build artifacts — regenerated by the prebuild.
  A fresh clone MUST run `cfg.buildCmd` (prebuild) before the converter, else no `dist/catalog.d.ts`.
- Tailwind pin: prebuild uses `@tailwindcss/cli` (added as a devDep). A Tailwind major bump could
  change compiled-CSS output; re-eyeball a contact sheet after any Tailwind upgrade.
- The `"types"` field in `packages/ui/package.json` points at the generated `dist/catalog.d.ts`. If a
  component file is added/removed, re-run the prebuild so the catalog + docs + bundle-entry pick it up
  (65-count will change). New components default to a floor card until a preview is authored.
- Preview animation fixes above are tied to the current recharts/motion behavior — if those deps bump,
  re-verify the affected sheets (ChartContainer, ShimmeringText, and any Wave-2 animated overlay).
