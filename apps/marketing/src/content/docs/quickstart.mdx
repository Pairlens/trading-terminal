There are three ways into Pairlens, and they all land on the same terminal.
The fastest is the **web terminal**: it opens in your browser with nothing to
install. The **desktop app** is free and auto-updating, and keeps your
exchange keys in your operating system's own keychain. If you'd rather read
the code you're about to trust, **run everything from source**.

## Open the terminal

Go to [terminal.pairlens.finance](https://terminal.pairlens.finance) and
you're on a live chart. Nothing to install, no account. On a phone, the same
URL opens the Mobile Trading Terminal: a chart-first shell with real order
entry through the same guarded order path.

Prefer it on your desk? Grab the installer for macOS, Windows, or Linux from
the [install page](/install) (or straight from the
[latest GitHub release](https://github.com/Pairlens/trading-terminal/releases/latest)).

Either way:

1. The terminal opens with a live chart, streaming directly from the exchange.
   No sign-up, nothing to configure.
2. Pick a market (BTC-USDT is the default) and watch candles stream in.
3. Sign in with your email **only if** you want workspaces synced across
   devices; everything works without it, stored locally.

## Connect an exchange

Open **Accounts** in the left nav, hit **Connect Account**, and pick your
venue. Paste the API key it issued you. Keys are used only to sign requests to
that venue, and never touch a Pairlens server.

<KeychainMock class="my-5" />

<Callout type="success" title="Your keys stay put">
  Pairlens has no server that could hold your secrets. On the desktop app,
  credentials live in the macOS Keychain, Windows Credential Manager, or Linux
  Secret Service. In the web terminal they stay in your browser, encrypted at
  rest, behind a vault you unlock with a password, a passkey, or Touch ID.
</Callout>

Not ready to risk real funds? Most venues issue demo keys. Choose **Paper**
when the wizard asks for a trading mode and rehearse the whole flow against the
exchange's own sandbox: same charts, same signals, no money at stake. See
[Connect an exchange](/docs/connect-an-exchange) for key-scoping advice and
[paper trading](/docs/paper-trading) for the three ways to practise.

## Run it from source

Everything the app does is in the public monorepo. Building it yourself
takes one tool (two for the native desktop shell):

Clone the repository and install workspace dependencies. Pairlens is a Bun
monorepo; one install wires up every app and package.

<CodeTabs
  client:visible
  tabs={[
    {
      label: 'bun',
      code: '$ git clone https://github.com/Pairlens/trading-terminal\n$ cd pairlens\n$ bun install',
    },
    {
      label: 'npm',
      code: '$ git clone https://github.com/Pairlens/trading-terminal\n$ cd pairlens\n$ npm install',
    },
  ]}
/>

<Callout type="tip">
  The maintainers use Bun and commit a `bun.lock`. `bun install` is the fastest
  path and the one CI runs against.
</Callout>

`bun run dev` boots the terminal in your browser on `http://localhost:3000`;
`bun run dev:desktop` builds the native desktop app (needs Rust).

<CodeTabs
  client:visible
  tabs={[
    { label: 'browser', code: '$ bun run dev' },
    { label: 'desktop', code: '$ bun run dev:desktop' },
  ]}
/>
